# Source-faithful RQ2 reproductions

This repository template preserves the security-relevant control flow of the
nine selected source workflows. Repository names and business operations are
adapted to an author-owned proof repository, while triggers, trust guards,
revision binding, artifact handling, and privilege boundaries remain intact.

An experiment is positive only when the secondary identity causes a unique
execution marker through the source-equivalent path. A skipped job, rejected
artifact, cache miss, failed write, or merely deployed-but-not-executed file is
recorded as a negative result.

The earlier `experiment/rq2/` templates are generic family controls and must
not be counted as source-specific exploitation evidence.
